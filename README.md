# JMX Professional Lab

A professional hands-on laboratory for learning Java Management Extensions (JMX) with Java 21, Open Liberty, Docker, and remote JMX clients.

## Goals

- Understand JMX architecture and APIs
- Build and manage custom MBeans
- Work with remote JMX
- Integrate JMX with Open Liberty
- Explore JMX security
- Understand production management architecture

## Technology Stack

- Java 21
- Maven
- Open Liberty
- Docker
- Docker Compose
- JMX
