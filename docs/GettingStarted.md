# Professional JMX Roadmap

A progressive, production-style project to learn and build JMX with Open Liberty.

We start with the JMX specification, build our own MBeans, expose them through an Open Liberty application, connect remotely from a separate Java client, and progressively deal with real-world concerns such as security, Docker networking, lifecycle, concurrency, notifications, failure handling, and observability.

## How This Roadmap Works

Each phase will be added as it is developed.

The links above can be updated whenever the repository structure or phase locations change. The roadmap intentionally does **not** prescribe a directory structure or implementation hierarchy.

The project will evolve progressively, and later phases may change direction based on what we learn in earlier phases.

---

## Goal

By the end of the project, we should have a practical understanding of:

- JMX fundamentals
- MBeans and MBeanServer
- ObjectName design
- Open Liberty JMX
- Remote JMX
- JMX security
- Docker networking
- MBean lifecycle
- Concurrency
- Notifications
- Failure handling
- Production MBean architecture
- JMX and modern observability

The focus is not only on making JMX work, but understanding the problems that appear when it is used in real systems.
